# TAXMINA Translator

Premium Android translator and language-learning app.

## Languages
English, Tajik, Russian, Kazakh, Uzbek, German.

## Included
- Online translation with offline phrase fallback
- Language switching and swap
- Text-to-speech
- Favorites UI
- Duolingo-style learning path
- XP, streaks and achievements
- Multiple-choice practice
- Vocabulary, grammar, listening, speaking and travel skill packs
- Dark premium Compose UI
- GitHub Actions APK build

## APK
Open Actions → TAXMINA Translator APK → Run workflow, or push to main. The generated APK is published as a workflow artifact.

Package: com.takhmina.translator
